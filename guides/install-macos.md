# "איך מתקינים את הבורד על Mac"

המדריך מיועד להתקנה חדשה של עותק הלקוח על macOS 13 ומעלה. כל לקוח משתמש בחשבונות ובנתונים שלו.

## 1. מתקינים את הכלים

- Node.js 24 LTS: בחרו macOS ואת המתקין באתר [Node.js](https://nodejs.org/en/download).
- Python 3.12: השתמשו במתקין של [Python ל-macOS](https://www.python.org/downloads/macos/).
- Git: פתחו Terminal והריצו `git --version`. אם macOS מציע להתקין Command Line Tools, השלימו את ההתקנה.
- מנוי MAX פעיל של Claude, בחשבון שלכם.

פתחו Terminal והריצו את מתקין Claude הרשמי:

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

סגרו ופתחו את Terminal אחרי ההתקנה, ואז התחברו:

```bash
claude auth login
claude --version
node --version
python3 --version
```

ההתחברות נפתחת בדפדפן. בחרו בחשבון שמחזיק את המנוי. אין להגדיר מפתח Anthropic API. ההתקנה נשענת על [Claude Code CLI](https://code.claude.com/docs/en/setup), ולא על אפליקציית Chat בלבד.

## 2. מורידים את הפרויקט

פתחו את קישור GitHub שקיבלתם. בריפו פרטי צריך להתחבר לחשבון GitHub שאליו נשלחה ההזמנה ולאשר אותה. אם מופיע 404, בדקו את החשבון וההזמנה.

בתפריט הירוק **Code** בחרו **Download ZIP**, וחלצו את הקובץ לתיקייה קבועה. לא מריצים מתוך הארכיון.

פתחו Terminal, הקלידו `cd ` עם רווח בסוף, גררו את התיקייה שחולצה לחלון ולחצו Enter. ודאו שבתיקייה מופיעים `package.json` ו-`setup.sh`:

```bash
ls package.json setup.sh
```

מי שכבר עובד עם Git יכול לשכפל את הריפו דרך כתובת ה-clone שמופיעה בתפריט Code.

## 3. מריצים התקנה והגדרה

```bash
bash setup.sh
```

הסקריפט מתקין את תלויות הבורד, דפדפן לבדיקות ותלויות Python. אשף ההגדרה יוצר התקנה פרטית ללקוח, תקני כתיבה, תבניות לסוגי הדף ופרויקט דפי נחיתה התחלתי.

הזינו את שם העסק ואת תיקיית ההתקנה. בחרו אם להפעיל בניית דפים. פרטי העסק, הנתונים והתוצרים נשמרים בתיקייה הפרטית; קובצי הקוד נשארים נפרדים. האשף מדפיס את הנתיבים שיצר.

אם אתם מגדירים את העותק לאחר שכבר הותקנו התלויות:

```bash
npm run configure
```

התקנה קיימת אינה נדרסת. הודעה על קובץ קיים דורשת בדיקה של ההתקנה שאליה נכנסתם, ולא מחיקה של פרופיל כדי להכריח את הסקריפט להמשיך.

## 4. בודקים ומפעילים

כאשר הבורד סגור:

```bash
npm run doctor
```

תקנו כל שורת **FAIL** לפני יצירת ריצה. אזהרה על יכולת אופציונלית כבויה יכולה להיות תקינה; ראו [תמיכה ויכולות](platform-support.md).

לאחר מכן:

```bash
npm run dev
```

פתחו בדפדפן את הכתובת שמודפסת, בדרך כלל `http://127.0.0.1:3000`. השאירו את Terminal פתוח בזמן העבודה. אין צורך להריץ ידנית את שרת דפי הנחיתה; הבורד מנהל את התצוגה.

להפעלה הבאה, חזרו לאותה תיקיית קוד והריצו `npm run dev`. לסגירה, ודאו שאין ניסיון פעיל, וחזרו ל-Terminal עם Control+C.

## 5. יוצרים את הריצה הראשונה

המשיכו לפי [מדריך הריצה הראשונה](first-run.md). יצירת דף כוללת אישור תוצרים בממשק. בדיקות ירוקות בהתקנה אינן מחליפות את בדיקת הדף שנוצר.

לתקלה בהתחברות, בפורט או בתיקיית הפרויקט: [פתרון תקלות](troubleshooting.md).
