# "איך פותרים תקלות התקנה נפוצות"

| מה רואים | מה עושים |
| --- | --- |
| GitHub מחזיר 404 | מאשרים את ההזמנה לריפו ונכנסים לחשבון GitHub שקיבל אותה |
| `node` או `claude` לא נמצא | פותחים Terminal מחדש אחרי ההתקנה; ב-Windows מוודאים שהכלי הותקן בתוך Ubuntu |
| Python ישן מדי | מתקינים Python 3.12 ובודקים `python3 --version` באותו חלון שבו מריצים setup |
| `No client profile is configured` | מריצים `npm run configure` בהתקנה חדשה, או בודקים את הנתיב ב-`.env.local` בהתקנה קיימת |
| האשף מסרב לדרוס קובץ | מוודאים שנכנסתם לתיקיית הבורד הנכונה; שומרים את ההתקנה הקיימת ומגדירים לקוח נוסף בתיקייה נפרדת |
| `doctor` מציג FAIL | מטפלים בסיבה המוצגת לפני הרצה; אפשר לשלוח את נוסח השגיאה לתמיכה לאחר הסרת פרטי לקוח |
| פורט תפוס | סוגרים עותק קודם שלכם, או בוחרים פורט פנוי לפי הדוגמה למטה |
| חסרה תבנית סוג דף | בודקים שההתקנה יצרה את תיקיית page-types ליד פרופיל הלקוח ושלא הוזזה |
| דפדפן מוקאפ חסר | מריצים שוב את התקנת Playwright כפי שמופיעה במדריך מערכת ההפעלה |
| המבקר לא השיב או לא עבר | קוראים את ההודעה בכרטיס ומשתמשים במשוב או בהחלטה אנושית; אין לפרש היעדר תשובה כאישור |
| הבידוד אינו נתמך | עוצרים; לא מסירים את מנגנון הבידוד. ב-Windows בודקים את טבלת התמיכה של הגרסה |
| חסרים נכסים | משלימים, מחליפים או מסירים דרך המשוב בממשק בשלב המתאים |

## שינוי פורט הבורד

בחרו פורט פנוי והשתמשו באותו ערך לבדיקה ולהפעלה:

```bash
PORT=4500 npm run doctor
PORT=4500 npm run dev
```

אין להגדיר `PORT` בתוך `.env.local`, משום ש-Next בוחר את הפורט לפני טעינת הקובץ. `PREVIEW_PORT` הוא פורט נפרד של תצוגת הדפים; שינויו בגרסת פרודקשן מחייב בנייה מחדש.

## עדכון גרסה

עדכנו רק כשאין ניסיון פעיל. שמרו את `.env.local` ואת תיקיית ההתקנה הפרטית. בעותק ששוכפל ב-Git אפשר למשוך גרסה מאושרת, להריץ `npm ci` ו-`npm run doctor`, ואז להפעיל מחדש. בעותק ZIP חילצו גרסה חדשה לתיקיית קוד נפרדת וחברו אליה את ההגדרות הקיימות; אל תעתיקו נתוני לקוחות לתוך הקוד.

אם השתנו תלויות Python או דפדפן, הוראות הגרסה צריכות לציין להריץ שוב setup. אין לעקוף חסימת הרשאה באמצעות הפעלת כל הבורד כ-root או Administrator.
