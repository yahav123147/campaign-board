# תקן אסטרטגיית עיצוב לדף מכירה

## איך בוחרים פלייבוק
1. מחיר: מוצר חינמי או מגנט לידים מקבל כיוון בהיר וישיר (White DR או Clean Light). מוצר בטווח מחיר בינוני מקבל כיוון עם אנרגיה ופעולה (Clean Light או Dark Premium). מוצר פרימיום, בטווח של עשרות אלפי שקלים, מקבל כיוון כהה ומהודר או כיוון נייבי-זהב סמכותי (Dark Premium או Elegant Authority).
2. הקשר הרכישה: מוצר טכנולוגי, כלי עבודה או תוכנה מצפים לכיוון כהה ומודרני. הצעה שנסגרת בשיחה אישית, בייעוץ או בליווי אחד על אחד, מתאימה לנייבי-זהב. מוצר בעלות כניסה נמוכה שמיועד לשימוש רחב מתאים לבהיר ואלגנטי. הצעה בטון תחרותי וישיר, שנשענת על הבטחת תוצאה מדידה, מתאימה לכהה עם ניגודיות חדה.
3. סוג מוצר: ספר או מדריך דיגיטלי, ומגנט לידים בתשלום משלוח בלבד, מקבלים כיוון של מכתב אישי לבן. קורס דיגיטלי או וורקשופ לקהל רחב מקבלים כיוון בהיר עם גלי SVG. ליווי, ייעוץ אישי או תוכנית קבוצתית מקבלים נייבי-זהב. כלי טכנולוגי או תוכנה מקבל כיוון כהה. השקה, קמפיין עם טיימר או שיווק שותפים מקבל כיוון כהה-דחוף עם טורקיז וליים.
4. טון הקופי: קופי קצר ודרמטי מתאים לכהה. קופי חם ואישי מתאים לנייבי-זהב או לבן-אישי. קופי ארוך במיוחד (מכתב מכירה מלא) מתאים רק לכיוון הלבן, כי זה הסגנון היחיד שמחזיק טקסט כה ארוך בלי להילחם בו.
5. המותג קובע את צבע ההדגשה: פלטת הקציר קודמת לזהב ולכל ברירת מחדל. אם ללקוח יש צבע מותג קיים, הוא הופך להדגשה על גבי הפלייבוק שנבחר, והרקע נשאר כפי שהפלייבוק מגדיר.
6. פלייבוק אחד לדף. בלי ערבוב, מלבד Hybrid המפורש למטה, ואף הוא לוקח מבנה מפלייבוק אחד בלבד.

## קטלוג הפלייבוקים

### Dark Premium
- מתי: מוצרי טכנולוגיה ובינה מלאכותית, השקות באנרגיה גבוהה, מיצוב "יוקרתי וחדשני".
- פלטה: בסיס שחור קר, צבע הדגשה אחד חם (זהב או צבע המותג), טקסט לבן.
- טיפוגרפיה: כותרות מודגשות מאוד (משקל כבד), אפס letter-spacing בעברית, ניגודיות גבוהה בין הכותרת לגוף.
- ריתמוס סקציות: הפרדה ברקע ובריווח בלבד. בלי קו מפריד מצויר. אנימציה ברמה גבוהה כשהמערכת תומכת בכך.

### Elegant Authority
- מתי: ייעוץ, ליווי אחד על אחד, מותג אישי, קהל מבוסס שמחפש אמון וסמכות, מוצר יקר.
- פלטה: נייבי כהה, זהב מעומעם כהדגשה, לבן ואפור בהיר.
- טיפוגרפיה: כותרות אמיתיות בגודל בינוני עד גדול, משקל כבד, אפס letter-spacing. בלי תוויות זעירות ומרווחות מעל הכותרת.
- ריתמוס סקציות: קווי מפריד חדים בין סקציות. אנימציה מינימלית, המבנה עצמו עושה את העבודה.

### Clean Light Professional
- מתי: קורסים ווורקשופים לקהל רחב, מחיר בינוני, טון נגיש ואנרגטי.
- פלטה: רקע בהיר, כרטיסים לבנים, כותרות בגוון כהה, כפתור פעולה בצבע ירוק או בצבע המותג.
- טיפוגרפיה: כותרות מודגשות וקריאות, גוף טקסט נקי ומרווח.
- ריתמוס סקציות: גלי SVG כהפרדה חזותית סטטית בין סקציות. אנימציה מינימלית.

### White Direct Response
- מתי: ספרים, מגנטי לידים בתשלום משלוח, מוצרים בעלות נמוכה, מכתבי מכירה ארוכים.
- פלטה: רקע לבן, טקסט שחור, סימון הדגשה עדין (ירוק רך או ורוד-בז'), בלי כפתורים צעקניים.
- טיפוגרפיה: קריאה כמו מכתב אישי, בלי אלמנטים דקורטיביים סביב הטקסט.
- ריתמוס סקציות: בלי הפרדה מצוירת, רק רווח לבן נדיב. בלי אנימציה, כדי שהדף יקרא כמכתב.

### Dark Funnel
- מתי: השקות עם טיימר, שיווק שותפים, טון תוקפני וישיר, דחיפות גבוהה, מחיר כניסה נמוך.
- פלטה: בסיס טורקיז כהה, הדגשה בצבע ליים, כפתור פעולה באדום.
- טיפוגרפיה: כותרות קצרות וחדות, ניגודיות קיצונית.
- ריתמוס סקציות: מעברי גרדיאנט בין סקציות. אנימציה בינונית, עם דגש על דחיפות.

### Hybrid
- מתי: כשאף פלייבוק בודד לא מתאים במדויק, למשל מוצר טכנולוגי עם קופי חם וסיפורי.
- כלל: פלייבוק אחד קובע את המבנה והריתמוס, ופלייבוק שני תורם רק צבעים או רכיב ספציפי. לעולם לא לערבב שני מבנים.

## חוקי ברזל
- אין קו דקורטיבי בצבע ההדגשה: לא hr, לא גרדיאנט אופקי, לא קו מתחת לתגית. הפרדה בין סקציות ברקע ובריווח.
- letter-spacing אפס בעברית, בכל כותרת ובכל תווית.
- תמונה מוכיחה כותרת. תמונה שאינה מוכיחה דבר לא נכנסת למפה.
- אין ג'נרוט של פנים המציג. תמונות אמיתיות בלבד מתיקיית הקציר.
- כפתור הפעולה חייב ניגודיות קריאה מול הרקע ומול הטקסט שסביבו.

## פורמט הפלט (מחייב, זהה להוראות שלב 3)
1. פסקת כיוון: הפלייבוק שנבחר ולמה, בהתבסס על הקופי המאושר ועל טבלת המותג משלב 1.
2. שורות REFERENCE_URL: ו-REFERENCE_DIR: רק כשיש פרויקט רפרנס מאושר בהקשר הריצה, כל אחת בשורה נפרדת:
REFERENCE_URL: <url>
REFERENCE_DIR: <path>
3. בלוק JSON אחד מגודר ב-```json, בדיוק במבנה הזה:
```json
{
  "playbook": "<שם הפלייבוק מהקטלוג למעלה>",
  "colors": { "base": "#hex", "accent": "#hex", "text": "#hex" },
  "vibe": ["<מילה>", "<מילה>", "<מילה>"],
  "specialElements": ["<אלמנט>", "..."],
  "hardBans": ["<איסור>", "..."],
  "imageMap": [
    { "harvestFile": "raw/<שם קובץ מטבלת התמונות>", "section": "<שם הסקציה בקופי, מדויק>", "proves": "<הכותרת או הטענה מהקופי שהתמונה מוכיחה>" }
  ]
}
```

## דוגמה (מותג בדוי, "אקמה")
אקמה מוכר ליווי עסקי אישי במחיר גבוה לקהל של בעלי עסקים מבוססים שמחפשים אמון וסמכות. הקופי המאושר חם וסיפורי, לא דרמטי. לכן נבחר פלייבוק Elegant Authority: נייבי וזהב מעומעם מתאימים למחיר, לקהל ולטון, והמבנה השקט של הפלייבוק לא מתחרה עם הסיפור.

```json
{
  "playbook": "Elegant Authority",
  "colors": { "base": "#1D2B46", "accent": "#D4B160", "text": "#FFFFFF" },
  "vibe": ["סמכות", "אמון", "שקט"],
  "specialElements": ["כרטיס עדות עם מסגרת דקה", "תג הישג ליד שם המציג"],
  "hardBans": ["קו דקורטיבי בצבע ההדגשה", "ג'נרוט פנים של המציג"],
  "imageMap": [
    { "harvestFile": "raw/01-portrait.jpg", "section": "Hero", "proves": "שנה אחת. תוצאה שונה לגמרי." },
    { "harvestFile": "raw/04-office.jpg", "section": "Authority", "proves": "עשר שנות ניסיון בליווי בעלי עסקים" }
  ]
}
```
